# MCP-Audit

Runtime security control plane for AI agents and MCP infrastructure.

## Overview

MCP-Audit is an industry-grade, open-source security platform for the **Model Context Protocol (MCP)** and the AI-agent supply chain.

### Core Pillars
1. **Discovery**: Inventory, registry, identity, provenance
2. **Analysis**: SAST, SCA, AI security, supply chain, risk
3. **Runtime**: Gateway, DLP, policy, behavior, drift, audit

Unified by the **Security Graph** (attack paths, data flow, permissions).
